# Assets

Drop these PNGs in this folder before building:

- `icon.png` — 1024x1024 app icon
- `adaptive-icon.png` — 1024x1024 Android adaptive foreground (transparent margins)
- `splash.png` — 2048x2048 splash artwork on `#0A0A0B`
- `favicon.png` — 48x48 web favicon

Until you add them, Expo dev client renders a default placeholder.
